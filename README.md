# PROCODE — AIML Projects

## Team Projects

PROCODE is an AIML capstone project consisting of two machine learning applications: one based on **Supervised Learning** and the other based on **Unsupervised Learning**. The projects cover the complete machine learning workflow, including data preparation, exploratory data analysis, preprocessing, model development, evaluation, backend/API development, web application development, model integration, testing, and documentation.

---

# Project 1 — Supervised Machine Learning

## Advanced Loan Approval

**Objective:** Build a machine learning system that predicts whether a loan application should be approved based on applicant and financial information.

The **Data** responsibility is handled by **Abdul**, who is responsible for dataset collection and preparation, data cleaning, exploratory data analysis, visualization, preprocessing, feature analysis, and documentation. **Kishore G** handles the **Machine Learning** component, including feature engineering, model development, training, evaluation, model saving, and integration. **Dyneswaran** is responsible for the **Application** component, including backend development, API development, frontend/web application development, model-backend integration, application testing, and final integration.

# Project 2 — Unsupervised Machine Learning

## Customer Persona Segmentation

**Objective:** Use unsupervised machine learning to group customers based on their income and spending behaviour and identify meaningful customer personas.

The **Data** responsibility is handled by **Shalini**, who manages dataset collection and preparation, data cleaning, preprocessing, exploratory data analysis, visualization, feature analysis, and documentation. **Tamilselvan** handles the **Machine Learning** component, including K-Means model development, cluster formation, cluster analysis, cluster interpretation, model evaluation, and model integration. **Kishore S** serves as the **Application Developer and Team Lead**, responsible for backend development, API development, web application development, model-backend integration, application testing, final integration, and overall project coordination.

# Technology Stack

The projects are developed using the following technologies:

* **Python** — Core programming language
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical computing
* **Scikit-learn** — Machine learning and model evaluation
* **Matplotlib** — Data visualization
* **FastAPI** — Backend and API development
* **Streamlit / Web Application** — User interface and application development
* **Jupyter Notebook** — Data analysis and model development

# Team Goal

The goal of the PROCODE team is to collaboratively develop two complete machine learning applications while maintaining clearly defined responsibilities across **Data, Machine Learning, Backend, Frontend, Integration, Testing, and Documentation**. Through these projects, the team aims to demonstrate the practical application of both supervised and unsupervised machine learning techniques in real-world scenarios.
